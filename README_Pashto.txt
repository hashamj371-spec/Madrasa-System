د شاګردانو د ثبت سیستم — آفلاین Windows پروژه

مهم:
1) دا ZIP د سافټویر د سرچینې فایلونه لري؛ لا جوړ شوی EXE نه دی.
2) د EXE جوړولو لپاره Windows 10 کمپیوټر، Node.js او یو ځل د انټرنېټ له لارې د npm install اړتیا ده.
3) وروسته د پروژې په فولډر کې CMD خلاص کړئ او دا امرونه اجرا کړئ:
   npm install
   npm run dist
4) EXE به د dist فولډر کې جوړ شي. له جوړېدو وروسته سافټویر آفلاین چلېږي.
5) معلومات د اپلیکیشن په محلي براوزر ذخیره (localStorage) کې ساتل کېږي. د Backup مېنیو له لارې منظم بېک اپ واخلئ.
6) د کامرې اجازه په Electron اپ کې کار کوي. که کامره ونه پېژندل شوه، د حافظې څخه عکس انتخاب کړئ.
7) د چاپ کړکۍ کې Save as PDF انتخاب کړئ.

فونټ:
- په style.css کې د فونټ نوم MS Aeen دی.
- د خپل قانوني/اصلي فونټ فایل نوم MS_Aeen.ttf کړئ او د fonts فولډر ته یې واچوئ.
- که د فونټ نوم یا فایل بڼه توپیر ولري، د style.css په لومړۍ کرښه کې د فایل نوم بدل کړئ.
- د MS_pashto.exe په نوم فایل د فونټ فایل نه ګڼل کېږي؛ د فونټ اصلي فایل باید .ttf یا .otf وي. د فونټ د نصبولو EXE د font فایل پر ځای مه کاروئ.

د معلوماتو مهمه یادونه:
- د اپلیکیشن ډاټا د کمپیوټر په محلي پروفایل کې ساتل کېږي؛ Backup واخلی، په ځانګړي ډول د Windows بیا نصبولو یا د اپلیکیشن حذفولو مخکې.
- د هر کتاب بشپړې نمرې په ډیفالټ 100 دي؛ غیرحاضري په هر ځل 5 نمرې کموي.
- د کیفیت حدود: تر 40 کم راسب، 40 تر 50 مقبول، 50 تر 70 جيد، 70 تر 80 جيد جدا، 80 تر 100 ممتاز.
- د درجې لپاره د کتابونو نوملړ د غوښتل شوي متن مطابق داخل شوی؛ د اعداديه او ځینو نورو درجو لپاره کتابونه لا په کارن-لاس اضافه/تنظیم کېدای شي.
